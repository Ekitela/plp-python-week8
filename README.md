# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python command-line program that combines four useful tools in one simple menu-driven application.

The four tools are:

1. **Simple Calculator** – Performs addition, subtraction, multiplication, and division.
2. **To-Do List** – Allows users to add, remove, and display tasks.
3. **Number Checker** – Checks whether a number is positive, negative, or zero and whether it is even or odd.
4. **Countdown** – Counts down from a number entered by the user.

The program also includes a main menu that allows users to select a tool or quit the application.

## Requirements

* Python 3
* Git (optional, for version control)

## How to Run the Program

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python toolkit.py
```

4. Select an option from the main menu by entering a number from 1 to 5.

## Example Menu

```text
===== PERSONAL MINI-TOOLKIT =====
1. Simple Calculator
2. To-Do List
3. Number Checker
4. Countdown
5. Quit
What would you like to use?
```

## Project Reflection

This project helped me practice important Python programming concepts, including variables, input and output, conditional statements, loops, lists, functions, and modular program design.

The most useful part of the project was combining several different tools into one menu-driven application. I learned how functions can separate different parts of a program and make the code easier to understand and maintain.

I also practiced handling user choices and using loops to keep the program running until the user chooses to quit. Building the To-Do List helped me understand how lists can be used to store and modify information.

Testing each tool helped me identify and correct errors, especially indentation and program-flow issues. I also learned the importance of planning before implementation by creating `toolkit_plan.txt` before completing the program.

Overall, this project increased my confidence in writing Python programs and helped me understand how individual programming concepts can be combined to create a complete application.
