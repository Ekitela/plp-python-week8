PERSONAL MINI-TOOLKIT PLAN

1. Simple Calculator
The calculator performs basic addition, subtraction, multiplication, and division.

2. To-Do List
The to-do list allows the user to add, show, and remove tasks while the program is running.

3. Number Checker
The number checker asks for a number and determines whether it is positive, negative, or zero.

4. Countdown
The countdown tool asks for a starting number and uses a loop to count down to zero.
